---
📌 项目核心定位
市面上绝大多数 AI Agent 依赖固定预设调用集，能力固化、无法突破限制、报错无法自愈、图形化操作卡顿精准度差。
NEURA Agent 彻底解决所有痛点：
- 去调用集中转：AI 直接操控 Agent 内核，无需预设工具，不受能力短缺限制
- 自主迭代自愈：Agent 运行报错时，AI 自动检测、自动修改源码、热重载生效、自动重试任务
- 全电脑操控权限：命令行、代码运行、软件安装、图形化点击、窗口管理、文件操控全覆盖
- 智能软件复用：打开软件自动检测前台/后台进程，优先复用已运行程序，杜绝多开冗余
- 双模型架构：内置本地模型 + 全兼容第三方 API 模型，一键自由切换
- 轻量化桌面悬浮端：替代传统Web页面，悬浮球伸缩设计，HUD科技透明面板

📥 快速部署教程
环境依赖
- Python 3.9+
- Windows 10/11（完整图形化操控支持）
- 依赖库：pywinauto、psutil、httpx、shutil、asyncio 等
启动步骤
1. 克隆/解压项目至本地目录
2. 安装全部依赖：pip install -r requirements.txt
3. 修改 config.json 配置：选择模型模式、填写API密钥（API模式可选）
4. 启动项目：python run.py
5. 桌面自动弹出悬浮球，点击即可交互使用

⚙️ 核心配置说明（config.json）
所有AI开关统一置于配置最顶层，全局唯一互斥，自动规范化：
- use_builtin_model：开启自研本地NeuraLM模型（默认）
- use_deepseek_api：开启DeepSeek API模型
- api_provider：可选 deepseek/openai/doubao/yuanbao/custom
- custom_api_enabled：开启自定义任意大模型API
配置特性：任一模型开启，其余自动关闭，杜绝配置冲突，启动自动修复配置异常。
